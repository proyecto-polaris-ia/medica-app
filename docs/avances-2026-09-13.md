# Avances del Proyecto — Medica App

**Fecha:** 13 de septiembre de 2026

---

## 1. Agente de WhatsApp para Gestión de Citas

Sistema automatizado que atiende a pacientes por WhatsApp, consulta la agenda real en Supabase, propone horarios disponibles y reserva citas sin intervención humana.

- Webhook de Meta WhatsApp Cloud API con verificación y persistencia de mensajes
- Orquestador inbound que coordina normalización, contexto, agente y acciones
- Motor de disponibilidad que calcula slots libres (business hours − appointments)
- Reserva atómica con constraint de exclusión por proveedor (sin doble booking)
- Recomendación de próxima hora libre cuando no hay disponibilidad en el rango pedido
- Resolución de paciente a partir del contacto de WhatsApp
- Reprogramación de citas existentes

## 2. Flow Engine (Motor de Flujos Conversacionales)

Arquitectura determinística de tres capas que separa el control del flujo del LLM: el flujo avanza por estados definidos, no por lo que el modelo decida en cada turno.

- Motor determinístico con estados y transiciones declarativas
- Flujo de booking completo: fecha → servicio → doctor → disponibilidad → selección → confirmación → notas
- Persistencia de estado en `whatsapp_conversations.flow_state` (jsonb)
- Feature flag para rollback inmediato sin redeploy
- Compatible con path legacy (coexistencia)

## 3. Panel de Administración (Dashboard)

Interfaz web para que la secretaria y el dentista operen el consultorio sin depender de WhatsApp.

- **Dashboard general** — resumen operativo del consultorio
- **Gestión de citas** — crear, ver, cambiar estado (solicitada, confirmada, cancelada, reprogramada, atendida)
- **Horarios por proveedor** — configuración de business hours por dentista y día de la semana
- **Catálogo de servicios** — nombre y duración de cada servicio dental
- **Gestión de proveedores (doctores)** — alta y administración de dentistas
- **Registro de pacientes** — datos generales, teléfono E.164, notas
- **Expediente de paciente** — vista consolidada del historial del paciente

## 4. WhatsApp Command Center

Panel operativo para supervisar y dar mantenimiento al canal de WhatsApp.

- **Contactos** — lista y detalle de contactos vinculados
- **Conversaciones** — historial de mensajes y contexto de booking
- **Escalamientos** — cola de casos que requieren atención humana
- **Base de conocimiento** — entradas FAQ aprobadas que el agente usa para responder automáticamente

## 5. Seguridad y Guardrails del Dominio

Reglas duras implementadas en backend que el agente no puede violar.

- No diagnostica ni receta medicamentos
- No inventa horarios: toda disponibilidad viene de la base de datos
- No da precios definitivos por WhatsApp (invita a valoración presencial)
- Escala a humano ante dolor fuerte, urgencia, infección, alergia o solicitud de receta
- El LLM interpreta y redacta; el orquestador ejecuta las acciones deterministas

## 6. Infraestructura Técnica

- **Stack:** Next.js (App Router) + TypeScript desplegado en Vercel
- **Base de datos:** Supabase (Postgres) como fuente de verdad
- **Auth:** roles para dentista administrador y secretaria
- **Zona horaria:** America/Mexico_City, todo en timestamptz
- **Observabilidad:** módulo dedicado para trazabilidad de operaciones
